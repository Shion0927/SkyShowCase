# WeatherCue

## なんのアプリ？
SkyShowCase は、  
**「毎回天気を見に行かなくても、必要なときだけ分かればいい」**  
という考え方をベースにした、シンプルな天気アプリです。

天気を一覧で眺めるよりも、  
**生活に影響がある変化を“通知”で受け取ること**を重視しています。

---

## 主な機能

### 🌍 都市切り替え
- 現在地（GPS）
- 自分で登録した都市  
を切り替えて天気・通知を管理できます。

### ☀️ 天気取得
- 都市検索：Open-Meteo Geocoding
- 天気予報：Weathernews WXTech（ss1wx）
- 当日〜中期予報を取得し、アプリ内で統一フォーマットに変換しています。

### 🕒 タイムライン
- 今後 **重要な天気変化だけ** を時系列で表示
- 24時間 / 7日間 の変化を確認できます。

### 🔔 通知
- 天気ルールに基づいて通知を自動スケジュール
- 例：
  - 次に雨が降りそうな日
  - 気温が一定以上 / 以下になる日
- 通知の状態をログとして保存
  - `scheduled`（送信予定）
  - `suppressed`（条件不成立で抑制）
  - `failed`（権限などで失敗）

### 🧠 判断の理由（Insight）
- なぜ通知された / されなかったのかを確認できる画面
- 通知の考え方・最近の傾向をまとめて表示

### 🎛 調整（Tuning / MVP）
- 細かい設定ではなく、**フィードバックで調整**
- 「通知が多い / ちょうどいい / 少ない」を選ぶだけで、
  通知の出やすさ（bias）が変化します
- この bias は実際の通知判定ロジックに反映されます

---

## 独自(っぽい)ポイント
- **通知中心設計**の天気アプリ
- 通知結果を「なぜそうなったか」まで残すログ構造
- フィードバックによって通知挙動が変わる前提のUI設計

---

## 開発メモ
- ⚠️ **Xcode のビルドがかなり重い**です  
  特に初回ビルドやクリーン後は時間がかかるので注意してください。
- ローカライズは作業途中のため、  
  まれにキー文字列が表示される場合がありますが、
  通知の再スケジュールで新しい表示に更新されます。
